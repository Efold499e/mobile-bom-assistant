## 验收标准（真跑真验）

1. `python -m unittest discover -s converter/tests -p "test_*.py"` 全绿、0 skip。
2. 金样测试：三格式各 ≥1 个 fixture → 期望 STJ **全文比对**（meta/board/outline/speak/分组/`group_order_default`），diff=0。
3. 双面坐标陷阱单测：底面件输入 → 输出为顶视图坐标 + `side:"bottom"`，逐字段断言未做镜像。
4. 嘉立创坐标系单测：左下原点 y 向上输入 → canonical（左上原点 y 向下），断言翻转公式；标准版/专业版两套表头嗅探各一测。
5. 归一化表驱动单测至少覆盖：4k7 / 10KΩ / 10000 → 10k；104 → 100nF；2R2 → 2.2Ω；0R → 0Ω 跳线；毫/兆靠 m/M 大小写区分（10mF vs 10MF 类用例）；R/C/L 前缀推单位；双写值（如 `100nF(104)`）落 `value_speak`。
6. 极性推断单测（LED / 二极管 / 电解电容 / IC pin1，refdes × 封装关键词）；剔除单测（安装孔 / 基准点 / 机械件默认剔除）。
7. 默认序单测：先小后大、先矮后高、贴片先于插件、单面焊完再另一面（构造反例断言被排后）。
8. CLI 真跑：`python converter/bom2task.py converter/tests/fixtures/kicad_min.kicad_pcb -o build/out.json --check` 退出 0；`python tools/validate_stj.py build/out.json` 退出 0——**三个格式的产物都必须过 M0 校验器**。
9. 依赖红线：`grep -rnE "^\s*(import|from)\s+" converter/ --include=*.py`，运行时代码仅标准库（测试文件允许 unittest）。
10. `git tag m2-done`。
