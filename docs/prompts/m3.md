# M3 执行 Prompt —— 点位图 + 朝向标定 + 批量模式

> 给未来的我：本文件自足。开工先读 `docs/plan.md` §5、§6、§7、§9 与 M1 代码（runner/dispatcher/store），再读本文件。
> 总则：验收 = 真跑命令 + 截图留档；没跑过不许说完成；QQ/NapCat 汇报一律纯英文 ASCII。
> 前置检查：`git tag -l m1-done` 存在（M2 可尚未完成，本阶段不依赖 converter）。

## 目标

焊接循环长上「眼睛」：点位图（缩略图 + 全屏、跟随视角、状态着色）、朝向标定与九宫格方位播报（卡片第三行激活）、底面镜像渲染、批量模式（询问 / 全组点亮 / 提示音）。

## 输入文件

- `docs/plan.md`（§5 点位图规格、§6 批量句模板、§7 标定、§9 批量模式）
- M1 完成态 webapp 代码（可扩展；`converter/` 若存在则只读）
- `webapp/public/demo/demo.stj.json`（双面 + 批量 + 地标样例）

## 范围内

- `src/boardmap/`：Canvas 静态底图（板框 + 器件 bbox；着色：待焊淡灰 / 已完成绿淡显 / 已跳过虚线 / 批量组琥珀）+ 当前器件 DOM 高亮点 + CSS 脉冲（动画不重绘 Canvas，**无常驻 rAF——省电红线**）；默认「跟随当前」缓动；捏合缩放/平移、双击回全景；缩略图（上区右 1/3，只画点）点击 → 全屏。
- 朝向标定屏（第 5 屏）：板框 + 自动选地标（≤3）→ 旋转钮 0°/90°/180°/270° 或转手机同向 → ✓ 锁定；角度随任务持久化；未标定不报左右（只报图纸方位）。
- 九宫格方位词纯函数（板框三分线）+ 最近地标增强；接入卡片第三行；随标定角与镜像变换。
- 底面镜像渲染：当前单元 side=bottom 时地图切镜像视图、九宫格词跟随镜像（注意：翻面确认/重标**流程**是 M4，本阶段只做渲染与词变换）。
- 批量模式：进入 qty≥4 的组（阈值=代码常量，M4 才开放设置）→ 询问「N 颗 xxx 一起焊？」→ 同意：全组焊点点亮、每按完成 = 短提示音 + 短震动 + 卡片「第 x/N 颗」；拒绝：逐颗完整播报；剩 3 / 剩 1 里程碑口播（§6 批量句）。
- 安卓 `orientation.lock('portrait')`；iOS 监听旋转让全局旋转角做确定性补偿（尽力，不承诺）。

## 验收标准（真跑真验，证据进 `docs/qa/m3/`）

1. `npm run test` 全绿，新增必测：九宫格词断言矩阵（四角/中心/三分线边界 × 标定 0/90/180/270）；镜像下词变换；最近地标选择；标定旋转数学（含 359°→0° 环绕）；批量触发阈值判定。
2. 浏览器自动化截图 `docs/qa/m3/*.png`：四类状态着色的地图全景；当前器件脉冲高亮；批量组琥珀色；缩略图与全屏切换；批量询问框；同意后全组点亮；底面镜像视图与顶视图对照（两张都要有）。
3. 自动化断言：标定屏转 90° 锁定后，卡片第三行方位词发生对应变化（断言前后文案）；点缩略图 → 全屏出现且当前点在视野内；批量组同意后连续完成 3 颗，卡片「x/N」递增且提示音触发计数=3（WebAudio mock 计数）；拒绝后逐颗播报（speaker mock 句计数）。
4. 真机清单 `docs/qa/m3/device.md`：orientation.lock 生效（横持手机仍竖屏）；捏合缩放/双击回全景手感；脉冲动画肉眼流畅不闪；琥珀色深色下可辨；标定后「左右」与桌面真板一致（实测一次）。无真机则标注阻塞待机。
5. `npm run build` 成功；`npm run test` 全绿；converter 侧 `python -m unittest discover` 仍全绿（证明没碰坏）。
6. `git tag m3-done`。

## 边界（本阶段不许碰）

- 不改 `converter/`、`tools/`、`docs/stj-spec.md`、`demo.stj.json`（只读）。
- 不做：报菜名排序屏；收尾清单/补焊；总结屏增强；设置屏（批量阈值=代码常量 4，语速仍默认 0.9×）；翻面确认与重标流程；ASR；蓝牙翻页器。
- dispatcher 不新增指令语义（全屏/缩放/标定是 UI 层流程，不是新指令）；store 仅允许增量字段（标定角），禁止破坏既有 schema。
- Canvas 禁止进入常驻 requestAnimationFrame 循环。
