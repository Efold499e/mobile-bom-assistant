## 验收标准（真跑真验）

1. KiCad 板：`python converter/bom2task.py <真实板>.kicad_pcb -o examples/boardA.stj.json --check` 退出 0；`python tools/validate_stj.py examples/boardA.stj.json` 退出 0；`--check` 统计与「对着元件袋人工数数」一致，两个数字并排写进 `docs/m5-friction.md`。
2. 嘉立创板：同上四项全部成立（验证真实表头嗅探 + 坐标翻转对真实文件成立）。
3. 真机全流程 ×2 板并录屏存 `docs/qa/m5/`：导入统计人工核对 → 报菜名照袋点菜 → 朝向标定（对照真板方位念一次「左上/右下」核验）→ 焊完全部（必须实走：≥1 次返工短按、≥1 次长按撤销、≥1 次上滑跳过、跳过项走补焊）→ 总结屏截图。
4. 摩擦回填：`docs/m5-friction.md` 每条都有修复 + 回归测试（unittest 或 vitest）；不允许存在「修了但没测试」的条目。
5. 回归全绿：`python -m unittest discover -s converter/tests` 全过；`cd webapp && npm run test && npm run build` 全过。
6. 手机安装最新构建（版本号/构建哈希记入 report）；`git tag m5-done` 与 `git tag v1.0`。
