## 3. 语料挖出的转换器 bug（全部修复 + 回归，converter 43→49 单测）

| # | 缺陷 | 触发板 | 修复 |
|---|---|---|---|
| B1 | **sides 字段与实际面不符**：单底面板被写成 `["top","bottom"]`（spec §8-7 违约，校验器 E_SIDES 拦下） | Arduino-Nano/Micro、RPi-HAT/uHAT、Nucleo64、TI-LaunchPad×2（排针真的画在 B.Cu） | model.py 按 placements 实际面集合生成，规范序 |
| B2 | **无板框文件崩溃**（`TypeError: 'NoneType' object is not iterable`） | RoyalBlue54L-Feather（文件本体损坏，349 处括号失衡）、DevEBox（板框画在 Margin 层） | model.py 对 outline=None 抛 ValueError，CLI 干净报错 rc=2 |
| B3 | **地标位号重复**：同名 ref 的接插件选满 3 个地标 → E_DUP | microwave（POLY×3） | 地标选取按 ref 去重 |
| B4 | **重复位号丢件**：同组内重复 refdes 触发 E_DUP，整板被校验器拒收 | microwave 等老工程 | 重复位号自动加 `_2/_3` 后缀存活 + anomaly 提示；组 refdes 同步 |
| B5 | **板外件毒化任务**：设计里停在板外的螺丝/螺母/垫片（支架安装件）转出 y=-36 → E_RANGE | vme-wren（12 颗），带 1489 颗全板转通 | 中心出板框 >1mm 的件剔除并记入 anomalies |
| B6 | **零可焊件产出空 STJ**（校验器拒收，报错绕） | EuroCard / Hammond / Edgeberry / MR-diagrams×2（只有安装孔） | 转换器直接拒绝并给出计数（N 颗机械剔除 + M 颗板外丢弃） |
